# Build Menu QOL

## Description
Build Menu QOL is a small, client-side UI mod that improves the functionality of Valheim's vanilla hammer build menu. It adds a hotkey for Repair, and it adds the sidebar with the Filter search box and Repair button to the Recent menu. It also provides config options for remapping and showing/hiding the hint badges for all of the above.

## Features
-Repair mode gains a hotkey
-Recent menu gains the Filter / Repair sidebar
-Config options for mapping custom keys or key combinations for the repair hotkey, filter hotkey, and tab switching hotkeys
-Config options for showing/hiding hotkey badges for the repair button, filter box, and menu tabs
-Config options to make repair hotkey auto-equip or un-equip hammer and other gear contextually

Unlike the vanilla button for it, the repair hotkey doesn't require you to first open the build menu in order to swap to repair mode. You can swap directly to and from repair mode now while building other pieces, or even while in combat with the equip toggle and re-equip gear options (enabled by default). The other hotkeys function as they do in vanilla.

**Note if playing on controller:** Hotkey rebind options and show/hide toggles are limited to keyboard/mouse, since controller mappings can't be rebound and shortcut badges always show for controller menus. Meaning that controller implementation is limited to a hard-coded controller shortcut for repair mode: **Alt**/**modifier** (LT or LB on xbox, L or ZL on switch, L1 or L2 on playstation) **+** **Inventory** (Y on xbox, X on switch, triangle on playstation). The "Equip Toggle" and "Re-bind previous gear" options still work for controller use though, affecting when this combo works and what it does.

## Requirements
This mod needs Bepinex to be installed and running with your build of the game.

## Installation
Installing through a mod manager like Thunderstore, R2MM or Amethyst is the easiest way to get up and running with it. The Thunderstore manifest should declare the required Valheim BepInEx package as a dependency so compatible managers can install it automatically. 

For Manual Installation:
    1. Install BepInExPack for Valheim (if you haven't already)
    2. Download and extract the BuildMenuQOL archive
    3. Open your Valheim installation folder. In Steam, right-click Valheim → Manage → Browse local files
    4. Open BepInEx/plugins/. Create a new folder here and name it BuildMenuQOL
    5. Move BuildMenuQOL.dll from the extracted archive to the folder you just created
    6. Launch Valheim using your normal BepInEx-enabled setup.
The mod's configuration file is generated by BepInEx in Valheim/BepInEx/config after the plugin loads up with the game.

## Configuration
If you're using an in-game configuration tool like ModConfigs or Configuration Manager, there should be remap binding buttons you can use there for remapping the hotkeys. Otherwise just directly edit the config file for it in your Valheim/Bepinex/config folder. Updates to the config file are checked live, so they should update in-game as soon as you edit them.

For manual config edits, use Unity KeyCode names (e.g., 'Backspace' or 'LeftControl + P'). See the 'Properties' list on this webpage for references to every usable KeyCode: https://docs.unity3d.com/ScriptReference/KeyCode.html)

By default, the new repair hotkey is mapped to the BackQuote key (aka "backtick" - the ` key), since this key is not used by the game's default mappings, but is close enough for easy access.

## Compatibility
Although I’ve designed this mod to try to “stay out of the way” and haven’t found any compatibility issues with the ~60 other mods I’ve tested it with so far, other mods that alter Valheim's build menu, Filter field, Repair button, or related UI may potentially conflict.

These mods are tested and confirmed working with BuildMenuQOL despite modifying similar game files/code:
**SearsCatalog** - No issues found
**ValheimHotkeys** - No issues found
**LSQCraftyCarts** - Although this one modifies the same repair button that my mod targets, they don't get in the way of each other. Repair hotkey still works as intended
